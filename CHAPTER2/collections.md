# Collections (5)

A **collection** is an `unordered`   grouping of objects (called `elements`).  

## Notation

- `a ∈ A` — element `a` is part of the collection `A`  
- `a ∉ A` — element `a` is not part of `A`  
- `∅` — the empty collection

## Ways to Describe a Collection

### Explicit Enumeration

List all elements.  
Example:  
> A = {0, 1, 4, 7, -5} ≡ {4, 7, 0, -5, 1}

### Definition-Based (Rule) Notation

Describe elements by a property.  
Example:  
> B = { x ∈ A : x < 3 }

## Cardinality

The **cardinality** of a collection is the number of elements it contains.

**Notation:**  
- |A| = 5  
- |∅| = 0
