# Intersection (Doorsnede)

## Definition and Notation

- A ∩ B = { x ∈ U : x ∈ A **and** x ∈ B }  

> Note: U is the **universe**, the collection containing all elements.

## Disjoint Collections

Two collections A and B are **disjoint** if:  
A ∩ B = ∅

**Example:**  
All subcollections of a **partition** are disjoint.
