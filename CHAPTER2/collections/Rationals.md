# Rational Numbers

## Definition and Notation

- ℚ = { a/b : a ∈ ℤ, b ∈ ℤ₀ }  

## Properties

- ℚ is a **field**: closed under addition (+), multiplication (×), subtraction (−), and division (/) (excluding division by 0)  
- **Dense ordering**: between any two rational numbers x and y, there exists another rational number, e.g., (x + y)/2
