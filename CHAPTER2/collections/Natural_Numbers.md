# Natural Numbers

## Definition and Notation

- ℕ = {0, 1, 2, 3, 4, …}  
- ℕ₀ = {1, 2, 3, 4, …}  

> Whether 0 is considered a natural number is a convention; in this course, 0 **is** a natural number.

## Properties

- **Closed under** addition (+) and multiplication (×)  
- **Not closed under** subtraction (−) and division (/)  
- Has a **natural ordering** `<`  
- **Induction property:** every number `n ∈ ℕ` can be obtained starting from 0 by counting `n` successors  
- Ideal for describing **sequences, iteration, and recursion** — very important in computer science
