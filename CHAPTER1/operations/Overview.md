## Overview — Logical Operations

- [**Negation (`¬p`, NOT)**](/CHAPTER1/operations/Negation.md): true if `p` is false  
- [**Conjunction (`p ∧ q`, AND)**](/CHAPTER1/operations/Conjuction.md): true if both `p` and `q` are true  
- [**Disjunction (`p ∨ q`, OR)**](/CHAPTER1/operations/Disjunction.md): true if at least one of `p` or `q` is true  
- [**Exclusive Disjunction (`p ⊕ q`, XOR)**](/CHAPTER1/operations/ExclusiveDisjunction.md): true if exactly one of `p` or `q` is true  
- [**Implication (`p ⇒ q`, IF … THEN …)**](/CHAPTER1/operations/Implication.md): false only when `p` is true and `q` is false  
- [**Biconditional (`p ⇔ q`, IF AND ONLY IF)**](/CHAPTER1/operations/Biconditional.md): true when `p` and `q` have the same truth value
