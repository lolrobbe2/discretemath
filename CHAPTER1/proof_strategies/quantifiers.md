# Quantifiers

## Universal Quantifier

`Notation (statement):`
- `∀` — “for all”

**Example:**
- `∀ n ∈ ℕ : n ≤ n²`

---

## Existential Quantifier

`Notation (statement):`
- `∃` — “there exists”

**Example:**
- `∃ n ∈ ℕ : n = n²`

---

## Unique Existential Quantifier

`Notation (statement):`
- `∃!` — “there exists exactly one”

**Example:**
- `∃! n ∈ ℕ : n² = 49`
