# Propositional logic

A `statement` or `proposition` is an assertion that is either *true* or *false*.

## Examples
- “The Earth is a planet” is a proposition with truth value *true*  
- “The Earth is flat” is a proposition with truth value *false*  
- “Is there life on Pluto?” is `not` a proposition  
- “Sit down!” is `not` a proposition  
- “2 + 3 = 5” is a proposition with truth value *true*  
- “x y = z” is `not` a proposition (it depends on the values of x, y, and z)

The letters `p`, `q`, `r`, … are often used to denote propositions.

## truth table/collection
The set of truth values is denoted by `𝔹` (“b” from *Boolean* or *binary*):

`𝔹 = {true, false} = {1, 0}`

For a proposition `p`, it therefore holds that:

`p ∈ 𝔹`
