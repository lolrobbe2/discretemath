# Propositional logic

A `statement` or `proposition` is an assertion that is either *true* or *false*.

## Examples
- “The Earth is a planet” is a proposition with truth value *true*  
- “The Earth is flat” is a proposition with truth value *false*  
- “Is there life on Pluto?” is `not` a proposition  
- “Sit down!” is `not` a proposition  
- “2 + 3 = 5” is a proposition with truth value *true*  
- “x y = z” is `not` a proposition (it depends on the values of x, y, and z)

The letters `p`, `q`, `r`, … are often used to denote propositions.

## truth table/collection
The set of truth values is denoted by `𝔹` (“b” from *Boolean* or *binary*):

`𝔹 = {true, false} = {1, 0}`

For a proposition `p`, it therefore holds that:

`p ∈ 𝔹`

> [!NOTE]
> `All binary propositions must be elements of the set 𝔹,  
> since they can only take one of two possible values.`

## Proposition Types (2)

### Simple proposition (enkelvoudig)
A `simple proposition` is any proposition that can be translated into a `single logical variable.`

`Examples:`
- `p` = “It is raining”
- `q` = “The streets are getting wet”

---

### Compound proposition (meervoudig)
A `compound proposition` is obtained by applying logical operations to simple propositions.  
These operations are therefore defined in `𝔹`.

`Examples:`
- `p and q` = “It is raining and the streets are getting wet”
- `p or q` = “It is raining or the streets are getting wet”
- `not p` = “It is not raining”


---

## Summary

- `Propositional logic` studies statements (propositions) that have exactly `one truth value`: *true* or *false*.
- A proposition must be declarative; questions, commands, and expressions with undefined variables are `not` propositions.
- Truth values belong to the Boolean set `𝔹 = {true, false} = {1, 0}`.
- Every valid (binary) proposition must be an element of `𝔹`.
- `Simple propositions` can be represented by a `single logical variable` (e.g. `p`, `q`).
- `Compound propositions` are formed by applying logical operators (`and`, `or`, `not`, …) to simple propositions.
